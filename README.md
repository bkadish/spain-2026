# Spain 2026 — trip map

A generated map for a driving trip through northern Spain, 4–16 August 2026.

**https://bkadish.github.io/spain-2026/**

This repository holds one generated file. It is written by `trip-webmap` in a
private repo, from a Google Sheet that is the source of truth, and pushed here
so the map has a URL that works on any phone without an app or a login.

Nothing here is edited by hand. Nothing here is a credential.
